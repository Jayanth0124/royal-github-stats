# 👑 Cinematic GitHub Stats

Elevate your GitHub profile with premium, cinematic, and fully animated statistics cards. Built from scratch with Next.js and the GitHub GraphQL API, these cards use pure SVG mathematics, glassmorphism, and dynamic lighting to showcase your developer legacy.

![Cinematic Stats Preview](https://your-vercel-url.vercel.app/api?username=Jayanth0124&theme=royal)

*(Note: Replace `your-vercel-url` with your actual live Vercel link once deployed!)*

---

## ✨ Features

* **Real-time Data:** Fetches your actual Total Contributions, Current Streak, Longest Streak, and Top 3 Languages directly from the GitHub API.
* **Cinematic Aesthetics:** Uses glass-morphic panels, glowing lens flares, and elegant serif typography.
* **Heavy Animations:** Features smoothly rotating chronometer rings and rising metallic progress bars built with pure 60fps SVG animations (no CSS bugs).
* **Multi-Theme Engine:** Switch between 5 premium color palettes simply by changing the URL parameter.

---

## 🎨 Available Themes

You can customize the look of your card by appending `&theme=theme_name` to the URL.

| Theme Name | Aesthetic | URL Parameter |
| :--- | :--- | :--- |
| **Royal** (Default) | Obsidian & Champagne Gold | `&theme=royal` |
| **Midnight** | Deep Space & Neon Cyan | `&theme=midnight` |
| **Crimson** | Dark Ruby & Blood Red | `&theme=crimson` |
| **Emerald** | The Matrix & Mint Green | `&theme=emerald` |
| **Amethyst** | Void & Deep Purple | `&theme=amethyst` |
